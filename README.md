# 🚀 Наскрізна аналітика продажів та поведінки користувачів e-Commerce інтернет-магазину

## 📌 Опис проекту та мета
Цей проект демонструє побудову повного циклу (End-to-End) аналітики для інтернет-магазину меблів. Мета дослідження — вивантажити сирі логи поведінки користувачів та транзакцій, провести глибокий розвідувальний (EDA), маркетинговий та статистичний аналіз даних, виявити приховані бізнес-закономірності та візуалізувати ключові метрики на інтерактивному BI-дашборді.

**Стек інструментів:** Google BigQuery (SQL) ➔ Python (Jupyter Notebook / Google Colab) ➔ Tableau Public.

---

## 🛠️ Метрики інтернет-магазину (За результатами EDA):
* Загальний виторг (Revenue): **\$31,971,731.00**
* Кількість унікальних сесій: **349 545**
* Конверсія сайту (Conversion Rate, CR): **9.59%**
* Середній чек (Average Order Value, AOV): **\$953.51**
* Період дослідження: 3 повні місяці (листопад 2020 — січень 2021).

---

## ⚖️ Статистичний аналіз відмінностей та гіпотез (Python)
1. **Порівняння інтерфейсів (T-тест Стьюдента):** Перевірено різницю середнього чеку між ПК та смартфонами. Отримано `P-value: 0.3791` (більше 0.05) ➔ Різниця між Desktop (\$957.47) та Mobile (\$944.42) є випадковою. Мобільна версія адаптована ідеально.
2. **Аналіз авторизації (Z-тест часток):** Доведено, що конверсія зареєстрованих клієнтів (9.95%) є статистично вищою за конверсію гостей (9.56%) з `P-value: 3.4677e-02` (менше 0.05).
3. **Щоденний виторг (Тест Манна-Вітні):** Оскільки критерій Шапіро-Вілка відхилив нормальність розподілу фінансових показників (p < 0.05), тест Манна-Вітні підтвердив значущі відмінності у щоденних обсягах продажів між групами користувачів (`U-statistic = 352.0`, `p-value = 0.0000`).
4. **Порівняння каналів (Критерій Краскела-Уолліса):** Підтверджено високозначущі відмінності у кількості щоденних сесій між маркетинговими джерела (`H-statistic = 208.4815`, `p-value = 3.5370e-50`).

## 📉 Аналіз взаємозв'язків (Кореляція Пірсона)
* Виявлено надзвичайно сильну залежність між щоденним трафіком сайту та виторгом (**r = 0.7911**, `p-value = 6.4835e-21`).
* Доведено синхронність глобальних продажів між континентами Americas, Europe та Asia (**r > 0.67**), що вказує на єдиний різдвяний сезонний фактор.
* Зафіксовано найсильнішу синергію між каналами `Organic Search` та `Paid Search` (**r = 0.81**), а також виявлено схильність клієнтів до комплексного меблювання (кореляція між категоріями м'яких меблів та шаф становить **r = 0.67**).

## 📈 Головні бізнес-інсайти та аномалії
* **Аномальний січневий сплеск:** Окрім грудневого передноворічного буму, виявлено потужний ізольований сплеск продажів в районі 10 січня, повністю забезпечений вертикальним зростанням каналу `Organic Search`. Це свідчить про довгостроковий ефект SEO або вірусне охоплення бренду в медіа.
* **Парадокс Чорної п'ятниці:** Наприкінці листопада акційні сплески були зафіксовані лише в Європі та Азії. Ринок США (головне джерело доходу) не показав зростання, що свідчить про програш конкурентної боротьби в Америці у цей вікенд.
* **Руйнування міфу про Email-маркетинг:** Зведені таблиці показали, що клієнти без підтвердженої пошти мають конверсію **10.01%**, що навіть вище за верифікованих користувачів (**9.53%**). Верифікація не стимулює продажі, тому компанії не варто примусово обмежувати клієнтів у кошику.
